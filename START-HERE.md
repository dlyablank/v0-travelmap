# Локальное демо Weekend Explorer

Для первого просмотра нужны только Node.js 24 LTS и интернет для установки пакетов.
Docker, PostgreSQL, S3 и API-ключи не нужны.

1. Распакуйте архив.
2. Откройте терминал в папке weekend-explorer.
3. Выполните по очереди:

```sh
npm ci
npm run db:generate
npm run dev
```

4. В браузере откройте адрес localhost:3000.
5. Чтобы остановить приложение, нажмите Ctrl+C в терминале.

Не копируйте .env.example в .env.local для первого просмотра: без этого файла
приложение автоматически использует встроенные 24 точки и хранит поездку и
закладки в браузере. Если переменная DATABASE_URL уже задана на вашем компьютере,
уберите её для этого запуска, чтобы включился демо-режим.

Что посмотреть за пару минут:
- общий экран: большая карта, вертикальные превью, лента;
- нажатие на место и переключение между карточками;
- фильтры и поиск;
- добавление двух-трёх мест в «Мою поездку», изменение порядка;
- построение маршрута и сохранение после перезагрузки;
- мобильный вид: сузьте окно браузера или включите эмуляцию телефона.

Это демонстрация направления продукта. Встроенные карточки используют фото
региона, готовых travel-видео пока нет. Можно добавить ссылку на свой ролик,
включив «Сохранить место только в этом браузере». Загрузка MP4 требует полного
локального стека (инструкции — в README.md).

Онлайн-карта и дорожный маршрут зависят от доступности внешних сервисов.
Если они недоступны, остаётся локальная обзорная карта, а маршрут явно
показывает расстояния по прямой без оценки времени.
