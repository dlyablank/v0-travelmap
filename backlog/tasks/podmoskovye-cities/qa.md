### Браузер, desktop (чистый профиль, затем legacy storage)
1. Без localStorage: селект «Подмосковье», в списке есть «Карелия», подпись угла «ПОДМОСКОВЬЕ», первый кадр — область вокруг Москвы с несколькими городами/кластерами, не только кремль Коломны.
2. Кремль Коломны: видео `kolomna-kremlin.mp4` играет; автор Андрей Елбаев; лицензия CC BY 3.0; добавление в поездку работает. Бобренев: `/media/fallback.svg`, текст «Видео этого места пока нет» / «Иллюстрация · видео пока нет», в поездку добавляется.
3. Поиск: Сергиев Посад, Звенигород, Клин — у каждого 3 места; метка лавры на карте у Сергиева Посада (не пустое поле). Координаты в данных привязаны к именованным объектам (OSM/Wikidata в комментариях).
4. `/trip` с Коломной (кремль + Голутвин) и Зарайском: две карточки; у Коломны «около 110 км от Москвы · 1–2 дня», Голутвин внутри Коломны; Зарайск отдельно с «около 180 км… · 1–2 дня». Reload сохраняет остановки.
5. Legacy storage `regionId: 'kolomna'` + `regionTrips.kolomna: ['kolomna-kremlin']` (+ отдельная поездка Карелии): после загрузки `regionId` → `podmoskovye`, кремль в `regionTrips.podmoskovye`, ключ `kolomna` снят, поездка Карелии не смешана с подмосковной.
6. Переключение селекта на Карелию: подпись «КАРЕЛИЯ», на карте карельские места (Суйсари и др.), каталог мест на месте.
