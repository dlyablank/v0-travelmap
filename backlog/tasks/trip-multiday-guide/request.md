# Запрос: многодневный гид-маршрут с отелями, едой и 2GIS

Дата: 22 октября 2026. Исходный запрос пользователя сохранён без изменения смысла:

1. Нужно переработать планировку маршрута. Сейчас в Vercel есть интеграция с 2ГИС. Нужно сделать так, чтобы при построении маршрута он разбивался на отрезки, которые реально посетить за 1 день, между отрезками были отели предложены по местоположению (несколько отелей с местом где человек оказывается вечером по маршруту), а также по ходу маршрута предлагались бы места для завтрака, обеда и ужина.
2. Во время построения маршрута нужно предлагать ещё места по ходу движения человека, чтобы он мог заодно увидеть что-то ещё.
3. Отчёт по маршруту должен быть в красивом виде, составленный из видео и описания, чтобы человек мог визуально понимать где он находится и куда ему ехать дальше. Плюс должен быть на 2гис проложен маршрут для человека на всех видах транспорта. Причём от транспорта зависит маршрут и зависят отели, рестораны и тд, то есть это динамический каждый раз новый маршрут!

## Подтверждённые требования (как сформулировал пользователь)

- Разбивка маршрута на **дневные отрезки**, реалистичные для одного дня.
- Между днями — **несколько предложений отелей** рядом с вечерней точкой маршрута.
- По ходу дня — предложения **завтрак / обед / ужин**.
- По ходу движения — **дополнительные места** «заодно увидеть», которые можно добавить.
- **Красивый отчёт** из видео и описаний: где сейчас, куда дальше.
- Маршрут на **2GIS для всех видов транспорта**; смена транспорта **пересчитывает** путь, отели, еду и доп. места (динамический план).

## Контекст продукта (не менять без согласования)

- Продукт: Weekend Explorer — video-first / map-first; не превращать в сухой AI trip planner без видео.
- Сейчас: `/trip`, однодневный план в локации, режимы car/walk/transit; линия/время — OSRM или fallback; внешние ссылки Яндекс Карт для частей маршрута; карта отображения — 2GIS MapGL JS (`NEXT_PUBLIC_DGIS_MAP_KEY`), серверный Places/Routing 2GIS в проект ранее **не входил**.
- Регионы: Карелия и Подмосковье (города). Поездка по выбранной локации/городу, коллекция мест в браузере.
- Язык UI — русский, светлая тема, desktop и mobile.

## Решения пользователя (22 окт 2026, вечер)

1. **Серверный ключ 2GIS есть** в переменных Vercel (отдельно от MapGL). В чат ключ не передавать. Локально — в игнорируемый `.env.local`; имя переменной согласовать в плане (`DGIS_API_KEY` или фактическое имя из Vercel). Fallback без ключа сохранить.
2. **Фокус — одни выходные**, не длинный тур. Вместо произвольного max дней: предлагать **оптимизировать маршрут** и давать **2–3 варианта**, чтобы успеть всё за выходные (типично 1–2 дня плана; при необходимости до 2 ночёвок в рамках weekend-сценария).
3. **Отели:** несколько предложений у вечерней точки; выбор не обязателен.
4. **«Заодно увидеть»:** сначала только места из каталога продукта.
5. **Отчёт:** только на `/trip` (без share/export в этой задаче).
6. **Навигация:** и Яндекс, и 2GIS (оба набора ссылок).

## Политика секретов

Не просить и не принимать ключ в чате. Пользователь добавляет/проверяет server env в Vercel и при необходимости копирует то же имя в локальный `.env.local`.

## Доступы и ограничения

- Не выдумывать рейсы ОТ, цены отелей и меню ресторанов.
- Секреты не писать в отчёты и не коммитить.
- Сохранять существующие правки пользователя и стиль продукта.
- Публикация — после PASS итогового QA, в уже подключённый Vercel-проект.
