# Weekend Explorer

Карта впечатлений и коротких поездок: Карелия, Коломна и окрестности. Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui (Radix), 2GIS MapGL JS (с обзорной картой MapLibre), Zustand, Prisma/PostgreSQL и S3-совместимое хранилище. Интерфейс на русском, светлая тема, desktop и mobile.

## Регионы

Переключатель региона находится справа в строке поиска. Карелия: 29 мест и 7 видео. Коломна и окрестности: 9 мест и 7 видео, включая кремль, улицы Лажечникова и Зайцева, вид на Москву-реку, музей пастилы, Старо-Голутвин монастырь и стрелку рек. Ещё две остановки без видео — Бобренев монастырь и Зарайский кремль; для них явно используются иллюстрации.

Переключатель «Куда отправимся» управляет только камерой единой карты. При ручном перемещении он автоматически показывает ближайший регион. Выбор региона не меняет поиск, категории, ленту, закладки или поездку. Лента содержит места всех направлений; расстояние и группы закладок выбираются отдельно в фильтрах.

Видео, места и кластеры не пересекаются; карточки находятся на реальных координатах без соединительных линий. Одновременно показывается до пяти видео; если они не помещаются, отображается меньше. При перетаскивании уже видимые видео сохраняются до выхода за границы экрана. Основная карта использует 2GIS MapGL JS при настроенном ключе. Без ключа или при сбое SDK сохраняется обзорная карта MapLibre / Natural Earth / OpenFreeMap.

На телефоне верхние панели занимают 96 пикселей и используют кнопки со значками и доступными названиями. Крупная кнопка сбоку открывает видеоленту. Кнопка на самом видеомаркере добавляет место в поездку без открытия карточки. Нижней полосы «Ваша поездка» на карте нет.

«Моя поездка» открывает `/trip`: выбор города и группы добавленных мест с миниатюрами. Коллекция всех направлений сохраняется в этом браузере и не ограничена 20 местами; один маршрут ограничен 20 остановками выбранной локации. Настройки дня и маршрут работают для выбранного города, остальные места остаются в коллекции.

Семь коломенских роликов — разные 15-секундные фрагменты **двух** прогулок Андрея Елбаева (yelbayev), монтаж оригиналов — Лев Дьяконов. CC BY 3.0 заявлена на страницах Wikimedia Commons; эти внешние источники ещё помечены Commons как ожидающие независимой проверки лицензии. Точное происхождение, таймкоды и изменения: [CREDITS.md](public/media/CREDITS.md) и [KOLOMNA-SOURCES.json](public/media/videos/KOLOMNA-SOURCES.json). Звук убран, превью — до 7 секунд. Даты публикаций исходников не выдаются за точные даты съёмки.

## Подключение 2GIS

В Vercel добавьте `NEXT_PUBLIC_DGIS_MAP_KEY` в Settings → Environment Variables для Production и нужных Preview, затем выполните новую сборку. Локально переменная читается из игнорируемого `.env.local`. Пустое значение оставляет обзорную карту; при ошибке загрузки SDK или стиля приложение также переключается на неё.

Это отдельный **браузерный** ключ MapGL JS API: он доступен в клиенте и сетевых запросах. В кабинете 2GIS ограничьте его продуктом MapGL и доменами проекта. Переменные Vercel исключают ключ из Git, но не делают браузерный ключ секретным. Серверные ключи поиска и маршрутизации нельзя использовать в `NEXT_PUBLIC_*`. Сам ключ не сохраняется в репозитории и не выводится нашим кодом в журнал.

MapGL используется для основы карты, HTML-маркеров и линии маршрута. Планировщик, его OSRM / walking настройки и внешние ссылки Яндекс Карт остаются прежними; подключение серверных API поиска и маршрутизации 2GIS в эту замену картографического движка не входит. Авторство карты выводит штатный copyright-контрол 2GIS.

Проверки интеграции используют контрактный стенд SDK без реального ключа и платных запросов. В отдельных терминалах:

```bash
NEXT_PUBLIC_DGIS_MAP_KEY=mapgl-contract-fixture npm run dev
NEXT_PUBLIC_DGIS_MAP_KEY=mapgl-contract-fixture npx playwright test tests/e2e/mapgl.spec.ts
```

Эти проверки подтверждают работу маркеров, координат, общего экземпляра карты, касаний, воспроизведения и резервного режима. Они не проверяют настоящие тайлы, активацию ключа или ограничения доменов — это требует открытой карты 2GIS с действующим ключом.

## Быстрый запуск

Нужны Node.js 22.12+ (в облачной среде проверен 24.19), npm и Docker для локальной PostgreSQL. Для browser-тестов нужны Chromium и FFmpeg.

```bash
bash scripts/setup.sh
cp .env.example .env.local # только если своего файла ещё нет
bash scripts/dev-services.sh
```

В двух отдельных терминалах:

```bash
npm run storage:dev
npm run dev
```

Приложение слушает порт 3000. S3rver — локальный сервис разработки на порту 9000, доступный только на loopback; файлы сохраняются в `.storage/`. PostgreSQL слушает 5432 и хранит данные в Docker volume. Публичные демонстрационные логины из `.env.example` предназначены только для разработки.

Для запуска без внешних сервисов удалите `DATABASE_URL` из `.env.local`: 38 демо-точек, карта, фильтры, локальные закладки и поездки доступны сразу. В импорте включите «Сохранить место только в этом браузере». Загрузка собственных файлов требует S3; внешнюю ссылку можно добавить и без него.

Production-сборка:

```bash
npm run build
npm start
```

Не запускайте `next dev` и `next build` одновременно в одном checkout: они используют `.next/`. Каждый cloud task уже изолирован; отдельный Git worktree не требуется.

## Что работает

- Компактный первый экран выводит видеокарточки выше. В видеоленте есть обзорная мини-карта на локальных полигонах Natural Earth: текущая точка меняется вместе с роликом, нажатие возвращает к месту на основной карте. Это обзор без дорожной навигации; второй WebGL-плеер карты не запускается.
- Добавленные места видны в «Моей поездке», сгруппированные по локациям. Порядок и сохранение используют Zustand/localStorage. В панели поездки есть обложка из кадра выбранного места; она различает черновик, подтверждённый routing-ответ и предварительный план по прямой, показывает только рассчитанные расстояние/время.
- Блок автора в видеоленте и карточке показывает имя, ссылку на профиль (если задана), оригинал, дату съёмки и условия использования. Метаданные `credit.authorUrl`, `recordedAt` (YYYY-MM-DD), `rightsBasis` (`open-license`, `public-domain`, `author-permission`) задаются вместе с проверенными данными ролика. Для нынешнего демо указаны открытые лицензии/общественное достояние; личное согласование с авторами не заявляется. У неизвестного основания выводится нейтральная подпись. Система сбора/проверки разрешений и хранение новых полей в БД пока не реализованы.

- «Вдохновение рядом»: видимые видеокарточки показывают беззвучные 6-секундные циклы (до 4 на desktop и mobile), используют `previewUrl` и освобождают плееры вне экрана, при открытии карточки/диалога и скрытии вкладки. Reduced motion и экономия трафика оставляют постеры.
- Нажатие на видеокарточку открывает полноэкранную вертикальную ленту. Свайп/прокрутка, стрелки и клавиатура переключают ролики; у конца подборки запрашиваются новые ролики, при их отсутствии отображается конец ленты. Буфер держит текущий и два соседних плеера, воспроизводится только один. Звук сохраняет выбранное состояние между роликами. Есть закладки, поездка, авторство и возврат к месту на карте. Фотокарточки открывают обычную карточку места. Новые ролики автоматически из внешних источников не подгружаются.

- Места с видео не объединяются в кластеры, показываются крупнее и поверх фото. Первый обзор подбирает масштаб по видеоточкам; дальнейшее перемещение и фильтры остаются под управлением пользователя.

- Короткие видео проигрываются прямо в отдельных маркерах карты: до 5 видимых превью на desktop и mobile, без звука. При перемещении карты, открытии карточки/диалога, скрытии вкладки или карты декодеры освобождаются. Настройки reduced motion и экономии трафика отключают автоматические превью. Кнопка «Видео на карте» позволяет остановить их вручную; при отказе autoplay остаётся постер.
- Демонстрационные WebM и постеры находятся в `public/media/videos`. `Place.video.playbackUrl` — URL основного ролика, необязательный `previewUrl` — отдельного облегчённого превью (по умолчанию используется основной ролик). Для S3 интерфейс менять не требуется: передавать выдаваемый сервером/CDN URL; для приватного bucket уже есть `/api/media/`. Загрузка и хранение дополнительных preview/credit полей в БД пока не реализованы. Будущий конвейер S3 должен сохранять авторство/лицензию и формировать короткие MP4/WebM-превью, постеры и подписанные URL без передачи credentials клиенту.

- Интерактивная карта 2GIS с кластерами вертикальных превью, масштабированием, выбором места и плавным перемещением. Резервная карта работает на MapLibre. Полная карта OpenFreeMap подключается автоматически при доступности. При блокировке сети остаётся локальная географическая карта Natural Earth с настоящими контурами суши и озёр.
- Связанные карта и лента, поиск по названию/городу/региону, категории, фильтр радиуса поездки из Сортавалы, отдельная коллекция закладок, состояния загрузки и пустых результатов.
- Карточка места с описанием, навигацией между точками, закладкой и добавлением в поездку. На телефоне — нижняя панель места и закреплённая кнопка поездки, переключение карты/ленты, горизонтальные свайпы между местами.
- Один активный HTML5-плеер: MP4/WebM, 9:16, muted autoplay, loop, play/pause, звук, poster, обработка ошибок. Собственное видео получает миниатюру из первого декодированного кадра. Неактивные точки используют изображения.
- Импорт собственного файла до 50 МБ с проверкой контейнера и ограниченным чтением потока на сервере; приватный S3 bucket, случайные ключи и потоковая выдача с HTTP Range. Ключи S3 не попадают в браузер.
- Для YouTube — официальный privacy-enhanced embed после нажатия; для TikTok/Instagram — переход к оригиналу. Всегда можно открыть оригинал, если автор или платформа ограничили плеер. Чужие видео не скачиваются.
- Места сохраняются в PostgreSQL через Prisma. При выбранном локальном режиме карточка хранится в localStorage; видеофайл по-прежнему загружается в S3. Локальные места и закладки принадлежат текущему браузеру.
- Маршрут выбранного города до 20 остановок, удаление и перестановка, один/два дня, автомобиль/пешком, эвристический порядок ближайшей следующей точки с сохранением первой остановки. Настройки поездки и выбранные места переживают перезагрузку.
- Дорожные расстояния, время и линия OSRM; при недоступности сервиса или далёкой привязке к дороге — явно подписанный пунктир по прямой без выдуманного времени. Экспорт плана JSON, сохранение поездки на сервере, открытие навигации.

## Данные и медиа

В `lib/data.ts` — 29 именованных точек с реальными координатами: Рускеала, Ахвенкоски, Ладожские шхеры, Кивач, Кижи, Паасо, Валаам, Кинерма и другие. Координаты обозначают достопримечательности, а не гарантированные парковки или входы. Для островов нужен водный транспорт; маршрутизатор не подменяет его автомобильным подъездом.

В демо нет вымышленных кафе, отелей, цен или часов работы. Поэтому фильтры «Кафе» и «Отели» изначально пусты. Импортированные места могут иметь эти категории.

В демо есть семь открытых видео: Кижи (Public domain), Койриноя, Кивач зимой, Суйсари, Сюскюянйоки, Иййоки и паровоз в Рускеале (CC BY-SA 4.0). Пять новых роликов — фрагменты до 15 секунд в MP4, для карты отдельно подготовлены беззвучные превью до 8 секунд, около 120–230 КБ каждое. Авторы и лицензии указаны в карточках и CREDITS.md. Для остальных мест видео пока нет. Вместо случайных роликов используется одна атмосферная фотография **региона**, повторённая для демо-карточек, и локальная иллюстрация при ошибке. Это не фотографии каждой конкретной точки. Источник фотографии и ограничения её дальнейшего использования: [public/media/CREDITS.md](public/media/CREDITS.md). Перед публичной коммерческой публикацией замените учебную фотографию на собственные лицензированные фотографии конкретных мест. Код готов к уникальному `thumbnailUrl` и видео для каждого места.

## Переменные окружения

См. [.env.example](.env.example); реальные ключи храните в секретах окружения, не в Git.

| Переменная                                 | Назначение                                                                                                 |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`                             | PostgreSQL; без неё включается локальный демо-режим                                                        |
| `ROUTING_URL`                              | OSRM-совместимый автомобильный endpoint, включая `/route/v1/driving`                                       |
| `WALKING_ROUTING_URL`                      | Отдельный маршрутизатор с настоящим пешеходным профилем; без него показывается только расстояние по прямой |
| `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`    | Настройки S3-совместимого хранилища                                                                        |
| `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | Серверные credentials с правами Put/Get только для нужного bucket/prefix                                   |
| `S3_PUBLIC_URL`                            | Необязательный URL публичного CDN/bucket; без него файлы выдаёт `/api/media/`                              |
| `LOCAL_STORAGE_DIR`                        | Необязательный путь S3rver, по умолчанию `.storage/`                                                       |
| `CHROMIUM_PATH`                            | Путь к системному браузеру для Playwright                                                                  |

Для полной карты нужен HTTPS-доступ к `tiles.openfreemap.org`, для OSRM — `router.project-osrm.org`. Для внешних роликов браузеру нужен доступ к YouTube/его CDN; ограничения платформы могут действовать независимо от настроек приложения.

## Архитектура

```text
app/
  page.tsx, layout.tsx, globals.css
  api/places/          чтение/создание места и связанного Video
  api/trips/           постоянное сохранение Trip + TripStop
  api/route/           OSRM с таймаутом и честным fallback
  api/uploads/         ограниченная серверная загрузка в S3
  api/media/[...key]/  выдача приватных объектов с HTTP Range
components/
  explorer.tsx         экран приложения и фильтры
  explorer-map.tsx     browser-only MapLibre, кластеры, маркеры и маршрут
  video-player.tsx     один активный плеер / официальное встраивание
  import-dialog.tsx    импорт и выбор точки на карте
  trip-panel.tsx       остановки, порядок и построение маршрута
  ui/                  shadcn/ui-style Button и Radix Dialog
lib/                   типы, данные, Zustand, расчёты, валидация, Prisma/S3
prisma/                схема, SQL-миграция и идемпотентный seed
scripts/               повторяемая установка, сервисы, генерация, миграции
```

`Place → Video`, `Trip → TripStop → Place`. Аутентификации по заданию нет; идентификаторы и отдельные сущности позволяют позднее добавить владельца поездки, AI-рекомендации и бронирования, не смешивая их с картой и плеером.

Prisma и её in-process generator пакеты закреплены на одной версии. `npm run db:generate` использует официальный npm-distributed WASM compiler, поскольку cloud-прокси блокировал сервер нативных Prisma engines. Проверки TLS, package integrity и checksums не отключались. `npm run db:migrate` транзакционно применяет SQL из `prisma/migrations`, сохраняет SHA-256 миграции и использует advisory lock; это самостоятельный runner, не история `_prisma_migrations`. Не смешивайте его с `prisma migrate deploy` в одной базе без согласованного перехода. `db:seed` обновляет только 29 известных демо-точек, не удаляя добавленные пользователем.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
# При работающих PostgreSQL, S3rver и приложении:
npm run test:e2e
```

Vitest проверяет географические расстояния, эвристику порядка, данные, валидацию ссылок, успешный OSRM-ответ, ошибки и невозможный дорожный подъезд. Успешный OSRM-ответ проверяется fixture-ответом; это не проверка доступности публичного сервиса.

Playwright запускает Chromium для desktop и mobile: карта, переключение карточек, пустые результаты, localStorage после reload, построение маршрута, запись поездки в PostgreSQL, собственный синтетический MP4 → S3 → новая точка → HTML5 playback/pause → HTTP Range. Тестовый ролик одноцветный, создан FFmpeg для проверки плеера и не выдаётся за съёмку места. Тесты импорта создают записи; удаляйте их только в отдельной тестовой БД или используйте `npm run test:cleanup` после локального прогона (он удаляет исключительно точные тестовые записи и их объекты).

## Известные ограничения

- В текущей cloud-сети OpenFreeMap и публичный OSRM заблокированы. Локальная обзорная карта и fallback проверены; дорожный маршрут и время появятся после разрешения доменов. Черновик настроек среды сам по себе не применяет сетевую политику.
- Пешеходное время не выдумывается на основе автомобильного профиля: подключите walking-сервис. Время фильтра — только грубый радиус (расстояние по прямой / 55 км/ч), что подписано в интерфейсе. Время на посещение — плановая оценка, не часы работы.
- Два дня задают бюджет поездки, без бронирования и автоматического выбора ночлега. Ближайшая следующая остановка — эвристика, не глобальная оптимизация по дорогам.
- Регистрации, бронирований, пользовательского разграничения и модерации нет. Перед публичным открытием загрузок нужен внешний контроль доступа/квот и проверка контента. S3rver предназначен для локальной разработки, не для production.
- Проверены Chromium desktop и эмуляция телефона; отдельная проверка Safari/iOS на реальном устройстве не проводилась.
- PostgreSQL Docker volumes и `.storage/` надо резервировать отдельно в production. Публикация cloud-среды и восстановление в новой задаче не проверялись.

## Демо на Vercel

1. В Vercel выберите **Add New → Project → Import Git Repository** и репозиторий `dlyablank/v0-travelmap`.
2. Framework: **Next.js**, Root Directory: **./**, Node.js: **24.x**.
3. Install Command: `npm ci`; Build Command: `npm run build`. Output Directory оставьте по умолчанию. Настройки уже заданы в `vercel.json`.
4. Для первого демо **не задавайте** `DATABASE_URL` и `S3_*`: встроенные места и локальное сохранение работают без них. `.env.local` не публикуется.
5. Нажмите **Deploy**. После подключения GitHub обновления `main` будут запускать новый production-деплой.

В этом режиме можно оценить интерфейс, карту, фильтры и сборку поездки. Импорт внешней ссылки работает с опцией «Сохранить место только в этом браузере». Собственные MP4 и серверное сохранение требуют отдельной настройки PostgreSQL/S3; загрузку больших файлов на Vercel нужно переводить на прямую подписанную загрузку в S3 из-за лимита тела serverless-запроса.

## Буфер видеоленты и просмотр места

Лента держит не больше трёх HTML5-плееров: предыдущий, текущий и следующий ролик. Соседи используют `preload="auto"` и остаются на паузе; при переходе сохраняется тот же DOM-плеер и его буфер. При прохождении середины свайпа или прокрутки воспроизведение передаётся соседнему ролику ещё до отпускания пальца; возврат за середину возвращает предыдущий. Играет ровно один ролик. Для ленты из одного/двух роликов повторные слайды показывают обложку, без дублирования декодеров. При закрытии или выходе ролика из окна буфера его медиа-ресурсы освобождаются.

При `Save-Data`, типе соединения slow-2g/2g/3g или скрытой вкладке предзагрузка соседей отключается. Браузеры могут дополнительно ограничивать preload, поэтому мгновенное начало на любом соединении не гарантируется. Внешние YouTube/Instagram/TikTok-ролики не скачиваются для этого буфера.

Обложка остаётся до первого представленого видеокадра, ожидание дольше 300 мс показывает индикатор, внизу есть прогресс. Ошибка содержит кнопку повтора. В нижнем блоке ленты — название, место, автор/лицензия и кнопка «В поездку»; описание, дата и полное происхождение доступны через «О месте».

Кнопка «Смотреть видео» в карточке карты открывает ту же ленту. Если просмотр начат с карты, закрытие возвращает к текущему просматривавшемуся месту с восстановлением фокуса. Коллекция поездки и лента остаются общими для всех направлений, мини-карта следует за текущим роликом.

`tests/e2e/buffered-video.spec.ts` проверяет загрузку соседнего ролика до выбора, переиспользование его DOM-элемента, сохранение звука, единственный играющий ролик при быстрых переходах, экономию трафика, отложенный первый кадр, возврат на карту и буфер лент из 1–2 роликов.
