### Итоговый полный сценарий

На текущей финальной версии browser прогон прошёл: каталог Коломны → сохранить два места → отдельная поездка → добавить сохранённые → собрать авто → увидеть расписание → изменить границы дня → переставить → добавить рекомендацию → reload с сохранёнными данными. Дополнительный walking сценарий строит полный итог, меняет порядок, скачивает актуальный JSON и перезагружается. Собственный transit сценарий проходит смены режимов, настоящий fallback API, скачивание и честное серверное сохранение, reload и смену локации. Проверки проведены после завершения мини-задач разработчика; правок приложения после них не было.
